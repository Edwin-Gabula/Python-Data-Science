# Python Data Science

A structured journey through Data Science with Python, progressing from numerical computing and data manipulation to exploratory data analysis, visualization, statistics, and eventually machine learning.

## 📚 Learning Path

The repository follows a practical progression:

1. **NumPy** — Numerical computing and array operations
2. **Pandas** — Data manipulation and analysis
3. **Data Cleaning** — Preparing real-world datasets for analysis
4. **Data Analysis** — Exploring, summarizing, and extracting insights from data
5. **Matplotlib** — Foundational data visualization
6. **Seaborn** — Statistical data visualization
7. **Plotly** — Interactive data visualization
8. **Statistics** — Statistical concepts for data analysis
9. **Machine Learning** — Predictive modeling and applied machine learning
